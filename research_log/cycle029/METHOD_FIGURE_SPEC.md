# Method overview specification

Message: changing a supplied, spatially localized miner memory changes the intended relational helmet target under a fixed scene/query. Dual-stage REF conditioning is central; no autonomous memory acquisition is drawn.

| Stage | Input | Operation | Output / cardinality |
|---|---|---|---|
| Common observation | Same-condition image I and shared helmet query q | Existing visual encoders | Global evidence shared across the two identity trials |
| Supplied memory A/B | Miner mask + bbox + appearance crop for each identity | Externally supplied geometry; crop derived from I | Two alternative references, not two new scenes |
| Input conditioning | Crop appearance + bbox | REF input projection, scalar addition at REF | Reference-conditioned language state |
| Output conditioning | REF hidden + mask/bbox geometry, SEG prompt | Add reference context to SAM text prompt | Memory-conditioned segmentation prompt |
| SAM decoding | Prompt and image features | Same weights for A/B | Helmet A/B as desired schematic outputs; not new predictions |
| Training inset | Paired targets and soft prediction IoU | Diagonal vs strongest off-diagonal hinge | Training loss only; no inference target access |
| Evaluation inset | Saved binary masks and pseudo targets | Within-group IoU matrix | Fidelity, CMSA, IER; offline only |

Use blue for identity A and orange for B with explicit A/B labels; violet for REF conditioning, green for SAM, neutral gray for shared context. Solid arrows are inference/data flow; insets are separated from inference. The same-condition/fixed-geometry banner is prominent. Training/evaluation matrices are symbolic, with no fabricated numerical outcomes. No sample image is selected, no new qualitative example is added, and no model/scorer runs.
