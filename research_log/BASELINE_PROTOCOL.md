# Comparative baseline protocol — cma_baseline_val50_v1

Frozen for Cycle014, 2026-09-18. Authority: CHATGPT_REVIEW_013.md at `3d7c907`. This is a reconstructed development/compatibility set, **not a final benchmark**. Miner and helmet masks were regenerated with SAM from recovered boxes; they are pseudo-labels, not recovered original masks or independently annotated ground truth. Prior CMA development used this validation set. No final-test generalization claim follows from these comparisons.

## Common input and scoring contract

- Use exactly Cycle006 `val_eval_restored.jsonl` and `val_grouped_restored.jsonl`: 50 ordered groups, 100 identity trials per condition. Preserve group order and each `pair_ids` order. `cycle014/protocol_receipt.json` freezes manifest/scorer/degradation SHA256 and ordered identities. Image and mask bytes are pinned by Cycle006 `frozen_assets.json`; relocate paths without regenerating assets.
- Conditions are `clean` and `target15_b`, seed 0. Reuse `counterfactual_export.condition_image` and `group_seed`, not a reimplementation. Per-group RNG seed is the first eight hex digits of MD5(`0:{group_id}`), interpreted as an integer. Parameters: gamma 2.15, contrast .655, scale .405, noise sigma 23.5, blur .88. Degrade original RGB once, before each model's native preprocessing; both identity trials receive identical pixels. Record resulting image hash, model preprocessing, versions and generation settings.
- Fixed semantic query: “Based on the miner mask from the previous round, segment only the mining helmet worn by that miner.” Native special tokens and conversation syntax may bind the supplied miner cue, but must not add descriptive identity clues or helmet location/shape. Save rendered prompts before inference. No prompt sweep.
- Supplied memory is the frozen miner mask and recorded miner bbox. Geometry is unchanged across conditions. Appearance must come from that condition's image: degraded references must not secretly contain clean pixels. Do not run a predicted-miner first round. Seed native memory with the supplied cue. A mask may naturally include visible helmet pixels; that is part of the supplied miner evidence, not permission to read helmet annotations.
- Bbox-only methods receive the same recorded miner bbox, transformed into their native coordinate frame, and the same full image. Explicitly label this lower-information cue variant. A native mask tokenizer or masked crop uses the supplied miner mask, never the helmet target. Preserve original H×W in exports; remove native padding/crop transforms correctly, using nearest-neighbor for binary mask resizing or native logit postprocessing before thresholding.
- Target masks, target boxes, target names/IDs and IoU are evaluation-only. Do not expose them in model prompts, tools, candidate selection, memory updates or retries. Provenance IDs are bookkeeping only.
- Use released inference defaults for decoding, output selection and thresholding, frozen in the port receipt before scoring. No GT-selected proposals, best-of-N or score-driven retries. If several masks represent one requested target, document the official rule; do not invent a favorable selection after evaluation. Empty native outputs remain empty masks; runtime exceptions are reported as incomplete execution, never silently omitted.
- For Tier A, export exactly one prediction per identity and condition to the existing CMF JSONL. Report C and D separately: target mIoU, Fidelity, CMSA, mean/median identity margin, IER. `eval_counterfactual_memory_fidelity.py` is authoritative and unchanged: strict correct-IoU > max wrong-IoU; CMSA additionally requires both identities' correct IoU >= .5; IER requires wrong > correct and wrong >= .5. mIoU/Fidelity/IER are reference-weighted; CMSA is pair-weighted. Retain per-group IoU matrices and paired C→D changes. Do not pool C and D into the headline number.
- No diagnostic30 or confirmation30 in baseline selection, interface debugging, prompt/checkpoint/threshold choice. No CMA training or tuning in this cycle. CMA comparator is frozen base w15 REF-LISA, not a retrospectively selected local-repair variant. Existing Cycle008 exports can be reused with asset/condition provenance intact.

## Fairness tiers

Review014 terminology clarification: Tier A is an **identity-cue compatibility** tier, not a claim that every candidate implements memory. SegLLM is the native historical-memory comparator; GLaMM and RegionReasoner are region/reference-conditioned systems; SAMTok is a mask-token cue system whose relational-generation path still needs execution proof. CMF eligibility requires actual native conditioning in the executed port.

**Tier A** means the native interface can represent the supplied miner identity through a reference mask, masked appearance or region bbox. Run the same semantic question twice on the same image, changing only the native identity cue. Report all CMF metrics. This is interface eligibility, not evidence of successful relational segmentation or equal input information. Split the result table by mask/appearance versus bbox-only cue. Record model size, upstream training data and CMA's target-domain fine-tuning advantage; a comparison of released checkpoints does not isolate architectural superiority.

**Tier B** means no native identity/reference input. Do not duplicate an image/text prediction into two purported memory interventions, or feed it to the CMF scorer. If run on this fixed query, store one unconditioned prediction per group/condition. A separate descriptive `reference_agnostic_target_miou` may compare that single prediction with each frozen target and average the 100 IoUs; label explicitly that the query's prior-memory referent is unavailable and this is an unequal-information baseline. CMSA, Fidelity, margin and IER are **N/A**, not zero. Do not rank this row against Tier A as a memory result. A native category/relation task needs matching complete category/relation labels and a separately declared protocol; the two selected helmets are not automatically exhaustive category ground truth.

## Existing model-free interchange

No new adapter is needed: the existing scorer accepts generic JSONL with no CMA model, pair loader or tensor interface. A Tier-A port writes:

```json
{"group_id":"frozen-group","image_id":"frozen-image","query":"fixed semantic query","condition":"clean","memory_source":"supplied_miner","trials":[{"entity_id":"pair-A","prediction":"pred-A.npy","target":"target-A.png"},{"entity_id":"pair-B","prediction":"pred-B.npy","target":"target-B.png"}]}
```

Predictions and targets are binary H×W arrays (0/1 or 0/255); paths resolve from the manifest directory. Store checkpoint revision, repository revision, cue type, rendered prompt, image/memory hashes, generation settings and timings in a companion run receipt. The scorer measures masks; it cannot certify that a model actually consumed a reference. Tier-B runs use a separate single-prediction file and report, never this trials schema. Existing synthetic PNG/NPY/inline tests cover identity preservation through serialization; Cycle014 reran 15 focused scorer/export tests successfully. These tests establish plumbing only, not model performance.
